# Game Context Profiles

A context profile changes atmosphere, not architecture. It may supply accent, subtle surface treatment, hero/cover choice and transition context. Never fork navigation or data stores. Use only artwork already available through the stable offline artwork pipeline.

Scarlet/Violet: Paldea context. Paldea, Kitakami and Blueberry remain distinct. Contemporary adventure/academy atmosphere. Do not merge regional Dex progress.
Kitakami: regional/natural/festival atmosphere only when supported by internal assets.
Blueberry: academy/terrarium atmosphere only when supported by internal assets.
Legends Arceus: Hisui; restrained natural/historical field-journal atmosphere.
Sword/Shield: Galar; stadium/adventure identity through approved context art/accent.
Brilliant Diamond/Shining Pearl: Sinnoh; clean Sinnoh/game identity.
Let's Go: Kanto; friendly/light treatment.
Legends Z-A: use only verified supported game/context data and existing approved assets.

Before adding a profile: confirm app support, inspect existing artwork, define accent/art role, derive regions/Dex from existing architecture and test light/dark.
